# TTS-аудіо

Текст у мовлення **на вашій машині** — Kokoro, невелика нейрона
TTS-модель, що працює офлайн через ONNX Runtime. Без API-ключів, без
хмари: текст не покидає машину. Результат — артефакт `speech.wav`.

---

## Перед запуском

1. **Text** — що промовити (до 5000 символів; синтез на CPU
   приблизно в реальному часі, тож повна сторінка — це пара хвилин).
2. Натисніть **Prepare Env** — встановить `kokoro-onnx` і його
   wheels (ONNX Runtime, numpy, soundfile). Важко, один раз.
3. **Перший ран потребує й моделей**: позначте **Download the models
   if missing** — обраний варіант (~80 МБ `int8`; `fp16`/`full`
   більше) плюс файл голосів ~27 МБ потраплять у
   `~/.cache/pyshell/tts-audio`, спільний для всіх ранів. Без
   позначки і без моделей → exit 1 з точною інструкцією; відсутня
   передумова — це відсутній результат, ніколи мовчазне попередження.

## Поля

### Voice

- **Text** — текст для озвучення.
- **Voice** — курирований список (Heart/Bella/Nicole, Adam/Michael/
  Puck, Emma, George, Dora (іспанська), Siwis (французька), Sara
  (італійська), Alpha (японська), Xiaobei (китайська). Перша літера
  кодує мову (`a`/`b` англійська, `e` іспанська, `f` французька,
  `i` італійська, `j` японська, `z` китайська) — мова
  фонемізатора виводиться з неї автоматично.
- **Speed** — 0.5–2.0×, замовчування 1.0.

### Models

- **Model variant** — `int8` (малий, швидкий, замовчування), `fp16`,
  `full` (~310 МБ): компроміс розмір/якість.
- **Download the models if missing** — опційне докачування з
  прогрес-баром. Перервані завантаження не лишають пошкоджених
  файлів (`.part` перейменовується по завершенню).
- **Models dir** — де живуть моделі; замовчування
  `~/.cache/pyshell/tts-audio` спільне для всіх ранів.

---

## Результат

- **Results tab** — підсумок: голос і мова, тривалість аудіо, розмір
  файла, час синтезу (реальне число вашої машини, корисно для
  планування довших текстів) і картка `speech.wav`.
- **Артефакти** — `speech.wav` (WAV, рідні для моделі 24 кГц).

## Коди виходу

- `0` — аудіо записано.
- `1` — відсутня передумова (пакет / моделі — з точною інструкцією)
  або синтез зазнав невдачі.
- `2` — неправильні аргументи (порожній/завеликий текст, невідомий
  голос, швидкість поза межами).
