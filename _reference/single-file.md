# Single File Example

Демонструє PEP 723: маніфест лежить у коментарях самого `.py`, окремий
`pyshell.yaml` не потрібен. Сам скрипт нічого не робить — друкує отримані
значення й виходить.

## Поля

- **URL** — тип `url`, обов'язкове.
- **Timeout (seconds)** — ціле від 1 до 300, за замовчуванням 30.

Обидва оголошені в блоці `# /// script` угорі файлу. Відкрийте його поруч із
формою: кожен `[[tool.pyshell.inputs]]` — це одне поле, а `binding` описує, як
значення перетвориться на аргумент.

## Коли PEP 723, а коли pyshell.yaml

Inline-маніфест зручний, поки скрипт — один файл: усе в одному місці, нічого не
загубиться при копіюванні. Щойно з'являється тека з кількома модулями,
`requirements.txt` і власним README — беріть `pyshell.yaml`, він має вищий
пріоритет і читається без запуску Python.

## Чому файл зветься single-file.md

Кілька односкриптових прикладів лежать в одній теці `_reference/`, тому документ
названо за іменем скрипта — PyShell шукає спершу `<ім'я скрипта>.md`, потім
`pyshell.md` для всієї теки, і лише потім `README`.
