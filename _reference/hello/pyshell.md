# Hello Example

Друкує привітання задану кількість разів. Нічого не записує на диск, нічого не
надсилає в мережу — це найпростіший приклад того, як маніфест перетворюється на
форму.

## Поля

- **Name** — кого вітати. Порожнім лишити не можна: поле обов'язкове, і Run буде
  заблокований, поки воно порожнє.
- **Count** — скільки разів повторити, від 1 до 100. Межі описані в маніфесті,
  тож форма не дасть ввести 0 чи 500.
- **Uppercase** — перемикач. У командному рядку він або є (`--uppercase`), або
  його немає взагалі; значення `false` не передається.

## Що подивитись

Натисніть **Preview** у шапці — PyShell покаже точний командний рядок, який буде
виконано з поточними значеннями. Це найшвидший спосіб зрозуміти, як `binding` у
маніфесті перетворюється на аргументи.

Сам вивід — звичайні рядки в `stdout`, без структурованих подій. Приклади з
прогресом, таблицями й графіками — у `progress-demo.py` і `report-demo.py`.

## Навіщо цей файл

Цю панель ви зараз і читаєте: PyShell знайшов `pyshell.md` поруч зі скриптом і
показав кнопку **Docs**. Такий файл пишеться для того, хто запускає скрипт, на
відміну від `README.md`, який пишеться для того, хто читає код.

Виграє найконкретніший документ: спершу названий іменем скрипта
(`main.md` — так зроблено для односкриптових прикладів у `_reference/`), потім
`pyshell.md` для всієї теки, і лише потім `README`.
