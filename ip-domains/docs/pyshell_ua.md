# IP → Domains

Знаходить домени, які вказують на ту саму IP-адресу, опитуючи кілька відкритих
джерел. Пасивна розвідка: до самої цілі скрипт не звертається, тільки до
сторонніх API.

## Поля

- **Target IP** — адреса у форматі `93.184.216.34`. Підтримується лише IPv4:
  IPv6 та CIDR-діапазони не приймаються (ані формою, ні CLI). Передається
  позиційним аргументом і перевіряється регулярним виразом у маніфесті, тож
  форма відхилить хостнейм.
- **Sources** — які джерела опитувати. crt.sh шукає домени в SAN-полях
  сертифікатів, HackerTarget і ViewDNS роблять reverse-IP, Shodan дивиться свою
  базу хостів. За замовчуванням увімкнені три перші — ті, що не потребують ключа.
  Увага: crt.sh шукає сертифікати, **видані для самого IP-літералу**, а не домени,
  що хостяться на ньому, — це слабкий reverse-IP джерело. Порожній результат
  crt.sh не означає «доменів немає», лише «сертифікатів для цієї IP не знайдено».
- **Shodan API Key** — потрібен, лише якщо вибрано Shodan. Без нього це джерело
  просто пропускається (з рядком статусу), решта працює.
- **Skip DNS verification** — за замовчуванням кожен знайдений домен
  перевіряється зворотним резолвом, і в результат потрапляють лише ті, що справді
  вказують на цю IP. З увімкненим прапорцем ви отримаєте сирий вивід джерел:
  швидше, але зі сміттям. У цьому режимі пишеться `domains_unverified.csv`
  (одна колонка), замість перевіреного `domains_verified.csv`.
- **Verification threads** — скільки доменів резолвити паралельно під час
  перевірки. За замовчуванням 50. Більше значення пришвидшує перевірку, але
  навантажує локальний резолвер і мережу.
- **Max domains to verify** — обмеження кількості доменів, що йдуть на перевірку.
  Якщо джерела повернули більше, зайве відкидається (з поміткою в статусі), щоб
  вкладитися у таймаут. За замовчуванням 5000.

## Ключ Shodan

Значення зберігається в системному Keychain (сервіс `com.pyshell.app`) і
передається скрипту змінною оточення `SHODAN_API_KEY`. У `argv` воно не
потрапляє — інакше ключ було б видно в `ps aux` будь-якому процесу. Форма після
збереження показує не значення, а позначку, що секрет встановлено.

## Результат

Таблиця у вкладці **Results** і файли `.csv` / `.json` у вкладці артефактів.
`domains_raw.json` — знайдені домени (очищені, без перевірки); `domains_verified.csv`
— результати перевірки (домен, IP, статус), або `domains_unverified.csv` з одним
стовпцем, якщо перевірку вимкнено. Перевірений CSV пишеться по мірі резолву, тож
навіть примусове переривання залишає частковий файл. Артефакти пишуться в
`PYSHELL_OUTPUT_DIR`, а не поруч зі скриптом.

## Перед запуском

Опитування чужих API з чужої IP може виглядати як розвідка перед атакою.
Перевіряйте адреси, які вам належать або на які ви маєте письмовий дозвіл.
