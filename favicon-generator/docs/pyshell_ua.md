# Генератор фавіконок

Перетворює одне зображення на **повний сучасний набір фавіконок** — усе,
що колись запитає браузер, iOS чи PWA-лінтер, згенероване з одного
файла-джерела:

| Файл | Для чого |
|---|---|
| `favicon.ico` | застарілі браузери — 16+32+48 в одному мультирозмірному ICO |
| `favicon-16x16.png`, `favicon-32x32.png` | вкладка браузера, класика та ретіна |
| `apple-touch-icon.png` | домашній екран iOS, 180×180, **непрозорий** |
| `icon-192.png`, `icon-512.png` | PWA / Android-іконки манифесту |
| `site.webmanifest` | манифест, що під'єднує PWA-іконки (+ ім'я застосунку) |
| `snippet.html` | теги для `<head>`, готові до вставки |

Правила обробки свідомо консервативні: джерело **вміщується, ніколи не
обрізається** (логотип — не те, що рубати), нес square-джерела
летербоксаться на квадратний холст, прозорість зберігається всюди, де
це легально — крім `apple-touch-icon.png`, який iOS компонує на чорне,
тому завжди вирівнюється (на ваш колір фону, або на білий, коли фон
прозорий — звіт про це каже).

---

## Перед запуском

1. **Source image** — одне зображення, квадратне і ≥512px
   рекомендовано. PNG із прозорістю — ідеальний вхід; JPEG/WebP/GIF/
   BMP/TIFF теж працюють. Менші джерела апскейляться з попередженням;
   сильно неквадратні — летербоксяться (з попередженням).
2. Натисніть **Prepare Env** — встановить `Pillow`.
3. Натисніть **Run** (⌘↩).

## Поля

### Source

- **Source image** — те саме зображення, з якого генерується все.

### Content

- **App name (optional)** — пишеться у `site.webmanifest` як
  `name`/`short_name`. Манифест без імені не проходить PWA-перевірки
  встановлюваності — заповніть перед публікацією.
- **Background** — `transparent` (замовчування) або колір `#rrggbb`.
  Використовується для летербоксу нес-square-джерел та вирівнювання
  apple-touch. із замовчуванням `apple-touch-icon.png` отримує білий
  фон (iOS компонує прозорі іконки на чорне; чорна коробка — не чиясь
  мета).
- **Padding (%)** — відсоток холста, що лишається порожнім навколо
  іконки (0–25). Іконки домашнього екрана iOS та адаптивні Android
  врізаються в кути; 5–10% паддінгу тримає логотип подалі від зрізу.

### Output

- **Write the set here too** — реальна проєктна папка, щоб файли
  пережили ран. Замовчування: поруч із джерелом; набір завжди також
  потрапляє в робочу папку PyShell.

## Результат

- **Results tab** — таблиця файлів (ім'я, байти, призначення) і
  готовий до вставки сніпет `<head>`.
- **Артефакти** — вісім файлів вище.

## Коди виходу

- `0` — набір згенеровано, наскільки б поганим не було джерело
  (попередження — це результат, а не помилки).
- `1` — джерело не читається як зображення, або файли неможливо
  записати.
- `2` — неправильні аргументи (невідомий колір фону, паддінг поза
  0–25).
