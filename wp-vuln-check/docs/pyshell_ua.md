# Перевірка вразливостей WP

Відомі вразливості встановлених плагінів і тем WordPress — версії
читаються **точно** з хедерів Plugin Name/style.css у теці
wp-content (ніколи не вгадуються з фронтенду), звіряються з фідом
Wordfence Intelligence із PHP-стилем порівняння версій (`2.10`
після `2.9`), операторами діапазонів і нюансом патч-бекпортів
(патчена гілка означає, що сайт може вже бути безпечним на тій самій
версії).

WP-кут, якого OSV покрити не може — фактична діра cve-check.

---

## Перед запуском

1. Перенесіть **wp-content folder** із сервера. Вкажіть батьківську
   до wp-content — і версію ядра буде прочитано з
   `wp-includes/version.php`.
2. Вкажіть **Wordfence Intelligence API key** — безкоштовний:
   реєстрація на wordfence.com → Account → Intelligence API →
   generate. Зберігається в Keychain, надсилається як Bearer-токен
   через `WORDFENCE_API_KEY`. Фід v3 — із ключем; без нього скрипт
   виходить з інструкцією, а не імітує результат.
3. **Prepare Env** — встановлює `requests`. Натисніть **Run**
   (⌘↩).

## Поля

### Target

- **wp-content folder** — скануються plugins/ і themes/; головний
  PHP-файл кожного плагіна (той, що несе хедер — спершу
  названий-як-тека, потім будь-який з хедером) і style.css кожної
  теми. Однофайлові плагіни теж читаються. Пункти без Version-хедера
  звітуються чесно: усі їхні рекомендації — з приміткою про
  невідому версію.

### Feed

- **Wordfence Intelligence API key** — безкоштовний ключ (секрет у
  env).
- **Feed timeout (s)** — 10–120, типовo 60; фід — кілька МБ.

---

## Результат

- **Вкладка Results** — таблиця (software · version · vulns ·
  patched) і звіт:
  - **🔴 unpatched** — рекомендація покриває встановлену версію, і
    бекпорта нема: оновлювати.
  - **🟡 patched** — рекомендація збігається, але вендор
    забекпортив фікс у цю версійну лінію: перевірте рівень патча,
    перш ніж панікувати.
  - **⚪ невідома версія / без діапазона** — перелічено для
    розгляду, сказано як є.
  - Розділ приміток: нечитабельні теки плагінів, відсутня plugins/,
    версія ядра, коли знайдена.
- **Артефакти** — `report.md`, `findings.json`.

## Коди виходу

| Код | Значення |
|---|---|
| 0 | відпрацювало; знахідки — результат |
| 1 | нема плагінів/тем, фід недосяжний, або нема ключа |
| 2 | помилкові аргументи: не тека |

## Пов'язане

- **wp-exposure-check** — що сайт відкриває; **wp-audit** — ваш
  код; цей — чужий код; **log-attack-checker** — що атакуючі вже
  пробували.
- **cve-check** — JS/npm-бік і ядро WP, як видно з фронтенду.
