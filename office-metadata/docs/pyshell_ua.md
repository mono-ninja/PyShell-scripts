# Метадані Office

Показує, **що розказують про вас файли Word/Excel/PowerPoint**: приватний
інвентар, захований у документі — автор, останній редактор, компанія,
керівник, хвилини редагування, відбиток програми, назви аркушів і
слайдів, користувацькі властивості, вбудована мініатюра, виправлення,
коментарі, позначка макросів — плюс опційні «чисті» копії без
метаданих (оригінали не чіпаються).

Сучасний файл Office — це ZIP з XML-частин, і кілька з них існують
лише для того, щоб описувати вас. Усе читається напряму з ZIP
стандартною бібліотекою — без Office, без залежностей, файл не
покидає машину.

---

## Перед запуском

1. Оберіть **Source** — один документ, кілька або теку (рекурсивно з
   підтеками). Лише сучасні формати: `docx docm dotx xlsx xlsm xltx
   pptx pptm potx`; застарілі бінарні `.doc/.xls/.ppt` не є
   ZIP-контейнерами й повідомляються як непідтримувані, а не як
   помилки.
2. **Prepare Env** не потрібен — лише стандартна бібліотека.
3. Натисніть **Run** (⌘↩). Увімкніть **Також створити чисті копії**
   й вкажіть **Output folder**, якщо потрібні очищені версії.

## Поля

### Input

- **Source** — один / кілька / тека. Файли без метаданих
  звітуються як 🟢 чисті; нечитабельні (не ZIP) — повідомляються, без
  фатальності — крім випадку, коли зазнали невдачі *усі* файли
  (код 1).
- **Recursive (with subfolders)** — режим теки: заходити в підтеки;
  не-Office файли відмічаються як пропущені.

### Strip

- **Also write clean copies (strip metadata)** — вимкнено за
  замовчуванням. Коли ввімкнено: копії `<назва>_clean.<розш>` пишуться
  в **Output folder**. Частини docProps (автор, компанія, хвилини,
  мініатюра, користувацькі властивості) прибираються, `core.xml`
  замінюється порожнім. Виправлення, коментарі, вбудовані об'єкти й
  макроси — це **контент**: вони звітуються голосно, але лишаються
  автору на ручне вирішення. Оригінали не чіпаються.

## Результат

- **Вкладка Results** — таблиця (файл · тип · що лишається ·
  вердикт) і звіт по кожному документу: кожне знайдене поле як
  історія. Вердикт 🔴 **ідентифікаційний витік**, коли документ
  називає реальних людей чи організації (автор, останній редактор,
  компанія, керівник), 🟠 **метадані** — коли лишається тільки
  технічне, 🟢 **чисто** — коли нічого немає.
- **Артефакти** — `report.md`, `office_metadata.csv` (рядок на
  документ, кожне поле — колонка), `*_clean.*` при очищенні.

### Що тут означає «витік»

- **Ідентичність** — автор, останній редактор, компанія, керівник.
- **Відбиток** — програма + версія, шаблон, хвилини редагування,
  ревізія, rsid-підписи історії збережень.
- **Структура контенту** — назви аркушів/слайдів, мініатюра-прев'ю,
  коментарі (імена ревʼюерів), виправлення (неприйняті правки),
  вбудовані об'єкти.

## Коди виходу

| Код | Значення |
|---|---|
| 0 | відпрацювало; звіт показує, що знайдено |
| 1 | усі документи нечитабельні або не вдалося створити теку виводу |
| 2 | помилкові аргументи: не той формат, немає файлу/теки, `--strip` без `--output-folder` |

## Пов'язане

- **EXIF Inspect** — та сама перевірка приватності для фото (GPS,
  камера).
- **PDF Toolkit** — для PDF: strip показує й прибирає автора,
  продюсера, дати, вкладення.
- **Secret Scan** — шукає витікаючі креденшели в коді й конфіґах (та
  сама перевірка «що я витік» для розробників).
