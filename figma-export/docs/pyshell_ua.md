# Експорт із Figma

Міст від інструмента дизайну до іконкового конвеєра. Конвеєр
колекції закінчується спрайтом; його початок завжди був «якось
SVG-и з'являються в теці» — це і є те «якось»: **компоненти**
файла Figma (або одного його фрейма), експортовані як SVG,
названі за конвенцією спрайта, готові для **Icon Audit → SVG
Optimize → SVG Sprite Build**.

- **Токен** — персональний токен доступу Figma через Keychain
  (поле токена зберігає його; окремо: `FIGMA_TOKEN` у
  середовищі). Без нього — чесний вихід із рядком, де взяти
  токен, ніколи не імітований експорт.
- **Обсяг** — увесь файл або фрейм з `?node-id=` URL; кожен
  компонент під обсягом збирається (network наборів компонентів
  проходить до варіантів — кожен стан експортується окремо, під
  ім'ям «набір варіант»).
- **Імена** — імена Figma («icon/home», «Home Icon») слагуються
  рівно так, як це робить SVG Sprite Build, тож ніщо не
  перейменовується двічі; колізії отримують суфікс `-2` і про це
  кажеться вголос.
- **PNG** — опційно, у 1x чи 2x, для місць, куди SVG не дістає.

Чесна межа, показана живим запитом: **Variables API у Figma —
лише Enterprise**. Скрипт питає; 403 звітується як «не перевірено
— Enterprise-only», ніколи як «змінних нема». Вузли й
опублікові стилі — те, що потрібно іконкам — доступні на
будь-якому плані.

---

## Перед запуском

1. Візьміть персональний токен доступу: Figma → Settings →
   Security → Personal access tokens (досить read-only). Вставте
   його в поле токена один раз — PyShell збереже в Keychain.
2. Скопіюйте URL файла (або фрейма — з `?node-id=`).
3. **Prepare Env** — ставить requests. Натисніть **Run** (⌘↩).

## Поля

### Target

- **Figma URL** — `https://www.figma.com/design/<key>/Name`,
  опційно з `?node-id=…`, щоб обмежитись одним фреймом.

### Export

- **Also export PNG** — SVG — валюта конвеєра; PNG at 1x
  чи 2x опційний.
- **Per-request timeout (s)** — 5–120, типовo 30.

---

## Результат

- **Вкладка Results** — таблиця експортів (компонент ·
  експортовано як · svg · png) і звіт: нормалізації імен,
  суфікси колізій, нотатка про межу Variables, кроки конвеєра
  звідси.
- **Артефакти** — `<slug>.svg` (і `.png`, коли обрано),
  `findings.json`, `report.md`.

## Коди виходу

| Код | Значення |
|---|---|
| 0 | експортовано |
| 1 | нема токена / нічого експортувати / усі звантаження провалились |
| 2 | помилкові аргументи (не figma.com URL, нема ключа файла) |

## Пов'язане

- **Icon Audit / SVG Optimize / SVG Sprite Build** — три кроки,
  які годує цей експорт.
- **Color Palette** — сторона design-токенів (кольори) того ж
  хендоффу.
