# Мінімізація ассетів

Мінімізує CSS і JS через **системні бінарці** — terser для JS,
clean-css-cli для CSS, опційно autoprefixer (postcss-cli) для
вендор-префіксів. Обгортка, як [cURL](../../curl): мінімізатори —
ваші системні інструменти; цей скрипт — оркестрація: пошук файлів,
покрокові запуски, чесний звіт.

---

## Перед запуском

1. Переконайтеся, що інструменти встановлені (ран перевірить і скаже
   точний рядок, якщо ні):

   ```bash
   npm install -g terser clean-css-cli
   # лише для вендор-префіксування:
   npm install -g postcss-cli autoprefixer
   ```

2. Оберіть **Source** — один файл, кілька або папку (з фільтром
   CSS/JS і перемикачем **Recursive**).
3. Оберіть **Output folder** і натисніть **Run** (⌘↩). Python-залежностей
   нема — Prepare Env нічого не встановлює.

## Поля

### Input

- **Source** — single / multiple / folder.
- **Only** (режим папки) — CSS, JS чи обидва.
- **Recursive** (режим папки) — обходити підпапки; вихід зберігає
  структуру.

### Options

- **Vendor-prefix CSS (autoprefixer)** — запускає autoprefixer перед
  clean-css. Потрібні postcss-cli + autoprefixer; перевіряється лише
  коли справді обробляється CSS-файл і перемикач увімкнено.

### Output

- **Output folder** — куди пишуться `.min.css` / `.min.js`. Оригінали
  ніколи не змінюються.
- **Overwrite existing** — коли вимкнено, `.min`-файли, що вже є у
  виході, пропускаються (зі звітом, не мовчки).

---

## Результат

- **Results tab** — таблиця по файлах і підсумок (байт зекономлено,
  лічильники за статусами).
- **Артефакти** — `minification_report.csv`.

### Статуси

- **minified** — `.min`-файл записано; розміри та % економії показані.
- **already minimal** — вихід мінімізатора виявився більшим або рівним
  джерелу: `.min`-файл не пишеться. Трапляється для ручних або
  вже мінімізованих файлів; рядок — це результат, а не помилка.
- **skipped** — вхід `*.min.*` (мінімізувати мінімізоване — марна
  праця) або наявний вихід без Overwrite.
- **error** — бінарка зазнала невдачі на цьому файлі; примітка несе
  перший рядок її stderr.

## Коди виходу

- `0` — партію оброблено.
- `1` — немає системних бінарців (з точним рядком
  `npm install -g …`), непридатна вихідна папка, або кожен файл
  зазнав помилки.
- `2` — неправильні аргументи.
