# Перевірка розмітки

Чи валідні структуровані дані — і чи вони чогось варті: JSON-LD
парситься (`@graph` обходиться, масиви `@type` розгортаються) і
звіряється з **курованими формами schema.org** (YAML-дані:
обов'язкові й рекомендовані властивості по типах, з розумінням
вкладень — Product → offers → Offer зі своїми обов'язковими;
перевірки URL-подібних і датоподібних полів), microdata та RDFa
помічаються поруч, ідуть **звірка розмітки зі сторінкою**
(ціна з розмітки, якої нема у видимому тексті) і вердикт, якого не
дає жоден валідатор: **валідно, але без rich result** — обмежений
список Google (31 тип станом на березень 2026); тип поза ним — не
помилка, а «для Bing/Perplexity, не для Google».

Page SEO Audit витягує JSON-LD як сигнал присутності; цей скрипт —
його валідуючий брат.

---

## Перед запуском

1. Введіть **URL** сторінки.
2. **Prepare Env** — встановлює `requests`, `lxml`, `pyyaml`.
3. Натисніть **Run** (⌘↩).

## Поля

### Target

- **URL** — сторінка; один запит, решта офлайн.
- **Per-request timeout (s)** — 3–60, типовo 15.

---

## Результат

- **Вкладка Results** — таблиця (серйозність · перевірка ·
  сутність · деталь) і звіт:
  - **Вердикт, якого не дають валідатори** — по кожному
    топ-рівневому типу: 🟢 у списку rich-result Google, чи ⚪
    валідно-але-без-rich-result з приміткою про Bing/Perplexity.
  - **jsonld** — невалідний JSON, названий по блоках script.
  - **required / recommended / shape** — знахідки курованих форм
    по сутностях.
  - **vs-page** — суперечності ціни/назви.
  - **Інші синтаксиси** — кількості microdata/RDFa і примітка
    «один синтаксис на сторінку».
- **Артефакти** — `report.md`, `findings.json` (сутності з їхніми
  ключами, машиночитно).

### Файл даних

`schema_types.yaml` тримає список Google і форми по типах — обидва
старіють (Google прибирає типи, schema.org додає властивості);
оновлення — правка даних, не коду.

## Коди виходу

| Код | Значення |
|---|---|
| 0 | відпрацювало; знахідки — результат |
| 1 | недосяжно, або розмітки на сторінці нема |
| 2 | помилкові аргументи: URL без http(s) |
