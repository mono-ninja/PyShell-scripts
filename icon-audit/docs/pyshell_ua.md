# Аудит іконок

QA іконкового набору **до складання спрайта** — поки виправлення
ще дешеві. SVG Optimize мінімізує все, що знайде; SVG Sprite Build
мовчки перейменовує неконвенційні файли, синтезує відсутні viewBox,
префіксує id — і вмирає лише на тій єдиній колізії, яку не може
пережити. Цей скрипт — гейт перед обома.

Перевірки:

- **Різноманіття viewBox** — мішанина 24/20/16, що рендериться як
  непослідовні розміри; взагалі без viewBox (білд синтезує його з
  width/height — з приміткою, бо синтез — це здогадка).
- **Імена проти конвенції спрайта** — кожен файл, чий stem
  відрізняється від слага, буде перейменований **мовчки**
  (перелічено, яким саме); два стеми, що колапсують в один слаг, —
  колізія, на якій білд вмирає.
- **Fill проти stroke** — набір напів суцільний, напів контурний
  читається як два різні набори на сторінці.
- **Викиди stroke-width** — непослідовні товщини в одному
  контурному наборі.
- **Геометричні дублікати** — ідентичні дані шляхів (фарбування не
  входить у хеш) під різними іменами.
- **Вбудовані растри** — `<image>` чи `data:image/` усередині
  «SVG»: растровий баласт у векторному одязі, імунний до темізації
  через currentColor.
- **A11y-форма** — іконки з `<title>` (білд його витягує: опис
  належить місцю `<use>`), нагадування про `aria-hidden` на момент
  використання.
- **Невживані іконки** — із заданою текою коду кожен symbol id
  (`icon-<slug>`) і слаг грепається по кодовій базі;
  ніде не згадані іконки називаються іменами. Мертвий баласт у
  спрайті — це байти, які платить кожен відвідувач.

Конвеєр, який це гейтить: **Figma Export** → **цей** → **SVG
Optimize** → **SVG Sprite Build**.

---

## Перед запуском

1. Оберіть **Icon folder** — ту, з якої білдився б спрайт
   (без рекурсії, як і сам білд).
2. Опційно вкажіть **Теку коду** для перевірки невживаних.
3. **Prepare Env** — ставить lxml. Натисніть **Run** (⌘↩).

## Поля

### Input

- **Icon folder** — файли `.svg` (приховані пропускаються, як у
  discover-кроці білда).
- **Code folder (for the unused check)** — опційно: тека вашого
  проєкту. Кожен symbol id і слаг іконки грепається тут; ніде не
  згадані іконки називаються. `.git`, `node_modules`, теки
  залежностей і нетекстові файли пропускаються за дизайном.

---

## Результат

- **Вкладка Results** — зведена таблиця (перевірка · кількість ·
  деталь) і звіт: кожна секція з названими іконками і виправленням.
- **Артефакти** — `report.md`, `findings.json` (факти кожної
  іконки і сирий вивід кожної перевірки).

## Коди виходу

| Код | Значення |
|---|---|
| 0 | аудит відпрацював; знахідки — результати |
| 1 | у теці нема файлів `.svg` |
| 2 | помилкові аргументи (теку не знайдено) |

## Пов'язане

- **SVG Sprite Build** — білд, який цей аудит гейтить; його
  слаг-конвенція віддзеркалена тут, змінюйте спершу там.
- **SVG Optimize** — крок мінімізації після гейту.
- **Figma Export** — свіжий експорт, який варто прогнати через цей
  гейт.
