# Перевірка заголовків пошти

Діагностує, **чому лист потрапив туди, куди потрапив**: вердикти
SPF/DKIM/DMARC з `Authentication-Results` з аналізом вирівнювання,
ланцюжок Received з затримками по хопах і позначками TLS, фішингові
сигнали та прапорці вкладень — усе з збереженого `.eml`-файлу, нікуди
нічого не надсилається.

Четвертий акт поштової історії: **Email DNS Audit** (політика) ·
**Mail Probe** (дріт) · **DNSBL Check** (репутація) · **цей скрипт**
(сам лист). Локальний файл, стандартна бібліотека, нуль мережі.

---

## Перед запуском

1. Збережіть лист як `.eml` (Apple Mail: *File → Save As…*;
   Thunderbird: натівний формат; Gmail: *Show original* → завантажити).
   Бінарний `.msg` з Outlook — інший формат і не підтримується.
2. Оберіть **Source** — один лист, кілька або теку.
3. **Prepare Env** не потрібен — лише стандартна бібліотека.
   Натисніть **Run** (⌘↩).

## Поля

### Input

- **Source** — один / кілька / тека; лише `.eml`. `--recursive` у
  режимі теки заходить у підтеки; не-eml файли відмічаються як
  пропущені.
- Лист без `Authentication-Results` аналізується за ланцюжком і
  сигналами, і про це чесно повідомляється: ресивер не записав
  вердиктів.

---

## Результат

- **Вкладка Results** — таблиця (файл · від кого · SPF · DKIM · DMARC
  · вердикт) і звіт по кожному листу:
  - **Автентифікація** — вердикти ресивера (найвищий A-R заголовок,
    доданий фінальним ресивером; власні A-R посередників
    пораховані й відмічені), плюс аналіз вирівнювання: чи
    збігається `smtp.mailfrom` / `header.d` з видимим доменом From —
    точний, піддомен чи **не вирівняний**.
  - **Ланцюжок Received** — від найновішого, кожен хоп з позначкою
    🔒/○ TLS, хостами, IP, протоколом, міткою часу й очікуванням на
    цьому хопі; сумарний час транзиту.
  - **Вердикти фільтрів** — заголовки `X-Spam-*`, якщо є.
  - **Сигнали** — маркери розсилок, Return-Path ≠ From, Message-ID з
    іншого домену (поштова служба або підробка), хопи без TLS.
  - **Червоні прапорці** — провалені SPF/DKIM/DMARC, невирівняні
    домени, Reply-To на інший домен (форма фішингу),
    виконувані/макро-вкладення, заголовок Date далеко від зараз.
  - **Вкладення** — назва, тип, розмір, попередження про
    виконувані.
- **Артефакти** — `report.md`, `findings.json` (усе зі звіту, в
  машиночитному вигляді).

## Коди виходу

| Код | Значення |
|---|---|
| 0 | відпрацювало; звіт показує, що знайдено |
| 1 | усі листи нечитабельні (немає заголовків / не RFC 5322) |
| 2 | помилкові аргументи: не `.eml`, немає файла, порожня тека |

## Пов'язане

- **Email DNS Audit** — DNS-бік тієї ж історії (записи
  SPF/DKIM/DMARC) для вашого домену.
- **Mail Probe** — MX-хости, STARTTLS і сертифікати на дроті.
- **DNSBL Check** — репутаційні списки.
