# PDF Toolkit

Шість PDF-задач, які справді трапляються — merge, split, extract,
rotate, **зняття метаданих**, compress — із приватністю на першому
плані: strip (і compress) перебудовують документ лише зі сторінок, а
звіт показує, **що саме метадані збиралися витекти**, перед тим як
прибрати їх. Оригінали ніколи не змінюються.

---

## Перед запуском

1. Оберіть **Operation**.
2. Натисніть **Prepare Env** — встановить `pypdf`.
3. Оберіть один або кілька **PDF files** (merge склеює їх у порядку
   вибору; кожна інша операція виконується над кожним файлом
   окремо), натисніть **Run** (⌘↩).

## Поля

### Operation

- **Operation** — що робити:
  - **Strip metadata (privacy)** — прибрати info-dict, Adobe XMP-потік
    і вбудовані вкладення; чиста копія лишає лише сторінки.
    `name_clean.pdf`.
  - **Merge** — `merged.pdf` у порядку вибору.
  - **Split** — по одному PDF на сторінку: `name_page_001.pdf` …
  - **Extract** — задані діапазони сторінок у `name_extracted.pdf`.
  - **Rotate** — 90/180/270°, всі сторінки або частина →
    `name_rotated.pdf`.
  - **Compress** — зняття метаданих + дедуплікація об'єктів →
    `name_min.pdf`.
- **PDF files** — один чи багато. Той самий специфікатор сторінок
  застосовується до кожного файла в партії; специфікатор, що не
  вміщується в найменший файл, — чесна помилка, а не сюрприз.

### Pages

- **Pages** — `1-3,7,10-`, з 1, відкриті діапазони дозволені.
  Обов'язковий для extract; для rotate порожнє означає всі сторінки.
  Встановлення для інших операцій відхиляється громуче (exit 2) —
  прапорець, який мовчки ігнорується, це баг, а не зручність.

### Output

- **Output folder** — опційно; за замовчуванням вихідна директорія
  PyShell або поточна папка у standalone-рані.

---

## Результат

- **Results tab** — таблиця по файлах (✓/✗ · що сталося · розміри для
  strip/compress) і звіт. Для strip та compress звіт містить секцію
  «що мало витекти»: автор, створено-в, вироблено-в, дати
  створення/зміни, ключові слова, наявність XMP, вкладення. Вміст
  усе одно може витікати (текст, зображення, видимі вотермарки) —
  секція це каже.
- **Артефакти** — PDF-и операції плюс `pdf_toolkit_results.json`.

### Чесні обмеження

- **Compress ніколи не перекодує зображення.** Сканований PDF — одне
  велике зображення на сторінку і сильно не стиснеться; перекодування
  втратило б якість і мовчки не робиться.
- **Зашифровані PDF** отримують одну спробу з порожнім паролем (більшість
  «зашифрованих» файлів — owner-locked, без пароля); справжній пароль
  означає exit 1 з назвою файла.
- Зміни розміру від strip — побічний ефект, ніколи мета.

## Коди виходу

- `0` — операцію виконано.
- `1` — вхід не читається як PDF, вихідна папка непридатна, або кожен
  файл зазнав помилки.
- `2` — неправильні аргументи (непридатний прапорець, специфікатор
  сторінок не парситься або не вміщується).
