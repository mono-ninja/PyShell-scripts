# Image Converter

Конвертує зображення у формати **AVIF**, **WebP**, **JPEG**, **PNG**, **TIFF**,
**BMP** з регулюванням якості. Працює з одним файлом, групою файлів або цілою
папкою (опціонально рекурсивно). Скрипт нічого не відправляє в мережу й не
змінює оригінали — лише пише нові файли у вибрану папку.

## Поля

### Вхід

- **Джерело** — як обрати зображення:
  - *Одне зображення* — один файл.
  - *Кілька зображень* — довільний набір файлів.
  - *Папка* — усі зображення з директорії.
- **Папка з зображеннями** доступна лише для режиму «Папка». Опція
  **Рекурсивно** обійде підпапки й відтворить їхню структуру у виводі.

### Конвертація

- **Формат** — цільовий. AVIF дає найменший розмір, WebP — малий розмір із
  широкою підтримкою браузерів, JPEG/PNG — універсальні, TIFF/BMP — для сумісності.
- **Якість** — 1–100. Для AVIF/WebP/JPEG це якість стиснення з втратами; для
  PNG (формат без втрат) значення трактується як рівень стиснення: чим більше,
  тим менший файл і повільніше стиснення. TIFF і BMP пишуться без стиснення,
  тож значення на них не впливає.
- **Макс. розмір (px)** — пропорційно зменшити зображення до вказаної найбільшої
  сторони. `0` = без змін. Зменшення відбувається лише якщо оригінал більший за
  вказане значення (ніколи не збільшує).

### Вивід

- **Папка для збереження** — куди покласти результат. Підпапки створюються
  автоматично (для рекурсивного режиму).
- **Перезаписувати існуючі** — якщо вимкнено, файли, що вже існують у виводі
  з попередніх запусків, пропускаються (з поміткою «пропущено» у таблиці).

Якщо два вхідні файли претендують на одне ім'я у виводі (`photo.png` і
`photo.jpg` обидва дають `photo.webp`), другий отримує суфікс: `photo-1.webp`.
Реальне ім'я видно у стовпці «Статус» — `OK → photo-1.webp`. Так жодне
зображення не губиться незалежно від того, увімкнено перезапис чи ні.

## Анімація

Анімовані GIF/WebP/AVIF при конвертації у **WebP** або **AVIF** зберігають усі
кадри, тривалість і циклічність. При конвертації у JPEG/PNG/TIFF/BMP
зберігається лише перший кадр (ці формати не підтримують анімацію).

## Результат

У вкладці **Results** — таблиця по кожному файлу: статус, оригінальний і новий
розмір, відсоток зміни розміру, плюс підсумковий markdown-звіт. Прогрес
відображається нативним баром PyShell.

## Код виходу

- `0` — хоча б одне зображення сконвертовано або пропущено як уже наявне
  (пропуск — штатний результат, а не помилка).
- `1` — не знайдено зображень або кожне завершилось помилкою.
- `2` — некоректні аргументи або середовище не вміє писати обраний формат
  (AVIF потребує Pillow ≥ 11.3 або `pillow-avif-plugin`).

Окремі браковані файли не зупиняють партію — їхній статус видно у таблиці.
