# OG-зображення

Соцкартки стандарту 1200×630 — **вироблені, а не перевірені**.
Page SEO Audit перевіряє, що тег `og:image` існує; цей скрипт
робить файл, на який він вказує. Розмір читає кожен рендерер
прев'ю (родина Open Graph, `summary_large_image` X/Twitter).

Форма favicon-generator, застосована до соцсторони: один вхід →
набір + сніпет для вставки. Батч-режим — суть скрипта: у справжнього
сайту сотні сторінок, і CSV проганяє їх усіх через той самий
шаблон за один ран.

**Три фіксовані шаблони, не конструктор** (правило обсягу
pdf-toolkit):

- **Gradient** — діагональний перехід двох бренд-кольорів,
  заголовок знизу ліворуч;
- **Accent banner** — суцільна основа, акцентна смуга ліворуч,
  заголовок праворуч від неї;
- **Background image** — ваше фото, cover-fit (ніколи не
  стискається) і затемнене, щоб текст читався; читабельність понад
  картинку, сказано прямо.

Заголовки переносяться й автозменшуються (до чотирьох рядків),
підзаголовок сидить під заголовком, опційний логотип — ліворуч
вгорі, опційний бренд-шрифт замінює системний sans. Кожна картка
ідe з повним мета-сніпетом: `og:image`, `og:image:width/height`,
`og:image:alt`, `twitter:card`.

---

## Перед запуском

1. Оберіть **Mode** — одна картка чи батч із CSV.
2. Оберіть **Template** і два бренд-кольори (hex).
3. **Prepare Env** — ставить Pillow. Натисніть **Run** (⌘↩).

## Поля

### Input

- **Mode** — *Single card* (заголовок + підзаголовок) чи *Batch from CSV*.
- **Title** — заголовок сторінки так, як він має читатись на
  картці (переноситься й автозменшується, щоб влізти).
- **Subtitle** — менший рядок (опційно).
- **CSV of cards** (батч) — колонки `title`, `subtitle`
  (опційно), `out` (опційне ім'я файла без розширення); одна
  картка на рядок, порожні заголовки пропускаються, ліміт 500
  рядків.

### Design

- **Template** — градієнт / банер з акцентом / фонове зображення.
- **Primary color** — hex: початок градієнта / фон банера.
- **Accent color** — hex: кінець градієнта / акцентна смуга /
  відтінок затемнення.
- **Logo (optional)** — PNG із прозорістю найкращий; куток
  ліворуч вгорі. Зламаний логотип ніколи не вбиває картку.
- **Background image** — для шаблону з картинкою; cover-fit і
  затемнення для читабельності.
- **Font (optional)** — бренд TTF/OTF; інакше системний
  sans-serif.

### Snippet

- **Base URL** — коли заданий, сніпети вказують на абсолютні
  URL (`https://site.com/og/card.png`); інакше відносні імена
  файлів із приміткою.

---

## Результат

- **Вкладка Results** — таблиця карток (файл · заголовок · розмір)
  і звіт: для кожної картки повний head-блок; кроки деплою.
- **Артефакти** — `<slug>.png` на картку, `meta-snippets.html`
  (блок кожної картки, із коментарями), `findings.json`,
  `report.md`.

## Коди виходу

| Код | Значення |
|---|---|
| 0 | картки відрендерені |
| 1 | картка не відрендерилась (диск, нечитається зображення) |
| 2 | помилкові аргументи: немає заголовка, немає CSV, немає файлів, шаблон із картинкою без фону |

## Пов'язане

- **Page SEO Audit** — перевіряє тег `og:image` на живій
  сторінці; цей робить файл, на який він вказує.
- **Color Palette** — витягніть бренд-кольори сайту, вставте hex-и
  сюди.
- **Responsive Images / Font Subset** — інші доставочні кроки
  дизайн-лінії.
