# Перевірка hreflang

Багатомовна розводка під мікроскопом — по **знімку Site Crawler**:
взаємність alternate-посилань (A → B, але B ↛ A — Google
викидає односторонні пари), аудити кластерів (стандартна форма
зрозуміла: кожна сторінка declaring повний набір — це норма;
помилка — коли одна мова чи x-default вказує на **різні цілі**),
відсутній x-default, self-reference, валідність кодів (`pt-br`,
`english`, `xx` — кожен із правильним написанням) і здоров'я цілей
(alternate на неканонічну чи 404-сторінку; поза краулом —
позначено як неперевірюване, не як зламане).

Hreflang — властивість кластера: одна сторінка не може показати
зламану половину; тому це читає весь краул, а не один URL.

---

## Залежності

Потребує [**Site Crawler**](../../site-crawler)
(`com.pyshell.sitecrawler`):

1. Запустіть Site Crawler на сайті — він пише
   `site_snapshot.json` (оберіть теку виводу, щоб файл пережив ран)
2. Вкажіть цей файл у полі **Site snapshot** цього скрипта

Знімок мусить бути schema 2 (поля hreflang) — старий відхиляється
з інструкцією переклаулити.

## Перед запуском

1. Спершу краул (див. вище).
2. Оберіть файл **Site snapshot**.
3. **Prepare Env** не потрібен — лише стандартна бібліотека.
   Натисніть **Run** (⌘↩).

## Поля

### Input

- **Site snapshot** — `site_snapshot.json` від Site Crawler.

---

## Результат

- **Вкладка Results** — таблиця (серйозність · перевірка ·
  сторінка · деталь) і звіт, згрупований за перевірками:
  - **reciprocity** — односторонні alternate, названі в контексті
    обох кінців.
  - **x-default** — відсутній у кластері, чи вказує на кілька
    різних сторінок.
  - **duplicate-language** — код мови з кількома різними цілями
    всередині одного кластера.
  - **invalid-code** — регістр, імена-замість-кодів, невідомі
    коди.
  - **non-canonical-target / broken-target / outside-crawl** — куди
    alternate фактично ведуть.
  - **self-reference** — рекомендований Google-ом запис власної
    мови, якщо його нема.
  - **Не перевірено** — hreflang у sitemap проти HTML: знімок
    записує лише HTML-сторону; сказано, не вгадано.
- **Артефакти** — `report.md`, `findings.json`.

## Коди виходу

| Код | Значення |
|---|---|
| 0 | відпрацювало; звіт — картина розводки |
| 1 | знімок нечитабельний/застарілий, або в краулі нема hreflang |
| 2 | помилкові аргументи |

## Пов'язане

- **SEO Checks** — прохід по одній сторінці по тому ж знімку; його
  canonical-знахідки пояснюють частину non-canonical targets тут.
- **Sitemap Generator** — генерує hreflang-alternate в sitemap; цей
  скрипт аудитує те, що вже є.
- **Site Crawler** — створив знімок; переклауліть після виправлень.
