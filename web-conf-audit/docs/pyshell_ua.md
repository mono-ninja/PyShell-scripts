# Аудит конфіґу веб-сервера

Що конфіг веб-сервера справді дозволяє — форма fw-audit для
веб-сервера. Збережені файли **nginx**, **Apache** і `.htaccess`,
формат впізнається автоматично, розбір пасивний: лістинги тек,
банери версій (типові значення відсутніх директив включно),
TLS-протоколи й шифри за шкалою tls-audit (негації зрозумілі),
PHP-в-uploads (безпечні форми похвалені), основні security-заголовки
які оцінює Security Headers (його нулі тут пояснюються), ліміти
розміру завантажень, стиснення, помилки proxy Host.

Компаньйон Security Headers у парі «правила проти реальності» —
нічого не запускається від root, нічого не перезавантажується.

---

## Перед запуском

1. Перенесіть файл(и) конфіґа з сервера (`scp` або вставте у файл).
2. Оберіть **Source** — один конфіг, кілька або теку (рекурсивно з
   підтеками); файли без формату веб-сервера відмічаються як
   пропущені.
3. **Prepare Env** не потрібен — лише стандартна бібліотека.
   Натисніть **Run** (⌘↩).

## Поля

### Input

- **Source** — один / кілька / тека. Формат кожного файла
  впізнається за вмістом: nginx (`server {`, `location`,
  `ssl_protocols`…), apache (`<VirtualHost`, `<Directory`,
  `ServerTokens`…), `.htaccess` — за ім'ям файла або за
  apache-директивами всередині.
- `.htaccess` розбирається з приміткою про контекст: його правила
  діють у своїй теці й нижче; TLS і банери лишається на
  головному конфізі.

---

## Результат

- **Вкладка Results** — таблиця (файл · формат · critical ·
  warnings · good · вердикт) і звіт по кожному конфіґу:
  - **listings / banners / tls / php-uploads / headers / uploads /
    proxy** — кожен прапорець зі своїм виправленням; прапорці
    *good* називають безпечну форму, коли вона знайдена (заблокована
    uploads-локація, `php_admin_flag engine off`, усі шість
    заголовків).
  - **Примітки** — типові значення, які діють, коли директиви немає
    (`server_tokens` типово on, `ServerTokens` типово Full,
    `client_max_body_size` типово 1m, `LimitRequestBody` без
    ліміту) — чесне «відсутнє ≠ гаразд».
- **Артефакти** — `report.md`, `findings.json`.

### Вердикти

🔴 critical (увімкнені TLSv1/TLSv1.1/слабкі шифри) · 🟠 to tighten
(лістинги, банери, php-в-uploads, відсутні заголовки, proxy Host) ·
🟢 sane · 🟡 see notes · ⚫ unrecognized.

## Коди виходу

| Код | Значення |
|---|---|
| 0 | відпрацювало; знахідки у звіті |
| 1 | жоден файл не відповідає формату веб-сервера |
| 2 | помилкові аргументи: немає файла, порожня тека |

## Пов'язане

- **Security Headers** — що долітає до браузера; цей скрипт
  пояснює його нулі.
- **TLS Audit** — живий handshake; список протоколів у конфізі —
  інший бік тієї ж правди.
- **FW Audit** — той самий пасивний розбір конфіґа для firewall.
