# Перевірка Wayback

Читає історію сайту через безкоштовний archive.org CDX API без ключів:
перший і останній знімок, графік активності по роках і — опційно —
**зниклі сторінки**: URL-и, що архів зафіксував як 200 і що сьогодні
відповідають 404, кандидати на карту редіректів для SEO-міграції.

---

## Перед запуском

1. **Domain or URL** — голий домен (`example.com`) або повний URL;
   інспектується саме хост. Субдомени за замовчуванням виключені
   (див. **Scope**).
2. Натисніть **Prepare Env** — встановить `requests`.
3. Натисніть **Run** (⌘↩). Запити до CDX — лише читання;
   **перевірка зниклих сторінок** — окремий перемикач, бо вона робить
   справжні GET-запити до цільового сайту.

CDX-сервер регулярно зайнятий: кожен запит отримує довгий таймаут і до
трьох спроб із паузою. Зайнятий archive.org — це exit 1: перезапустіть
пізніше, не дебажте.

## Поля

### Target

- **Domain or URL** — сайт, чию історію ви хочете. Глибокий URL
  годиться; для охоплення важливий лише його хост.
- **Scope** — *Site* (замовчування): лише цей хост. *Domain*: із
  субдоменами — може залити відповідь або впертися в rate-ліміти CDX
  на доменах із дикими картами; звіт скаже, коли ліміт рядків
  обрізав скан.

### Vanished pages

- **Check for vanished pages** — вимкнено за замовчуванням. Коли
  увімкнено: архівні URL-и цього хоста (спершу найдавніші за першою
  появою) опитуються на живому сайті; відповіді 404/410 стають
  кандидатами на карту редіректів.
- **Vanished check limit** — скільки архівних URL-ів перевірити,
  1–50 (замовчування 20). Справжні GET-и до цілі — будьте ввічливі.

### Query

- **Per-request timeout (s)** — замовчування 45; великий річний скан
  на CDX-сервері справді може тривати так довго.

## Результат

- **Results tab** — стовпчикова діаграма **місяців із знімками по
  роках**, потім звіт:
  - перший і останній знімок з розмахом у роках, роки/місяці зі
    знімками;
  - таблиця зниклих сторінок (архівний URL · перша поява · живий
    статус · вердикт), кожен рядок 🔴 зникла / 🟢 жива / ⚫ недосяжна /
    🟡 інше;
  - порада щодо редіректів із посиланнями на [Site
    Crawler](../../site-crawler) і [SEO Checks](../../seo-checks) для
    перевірки після міграції.
- **Артефакти** — `wayback_history.json` (таймлайн,
  машиночитабельно), `wayback_vanished.csv` (url · first_seen ·
  live_status · verdict), `report.md`.

### Чесне читання даних

- **Графік рахує місяці зі знімками** — місячний колапс над даними
  CDX, проксі активності, що насичується на 12/рік для густо
  архівованих сайтів. Це не сирий лічильник знімків.
- **Домен без знімків** — це знахідка, а не помилка: надто новий, ніколи
  не архівувався, або архівований під іншим хостом. Ран усе одно
  завершується з 0.
- **Недосяжні живі URL-и** звітуються окремо — кількість зниклих над
  напівлежачим сайтом була б брехнею.

## Коди виходу

- `0` — перевірку виконано. Зниклі сторінки — знахідки; порожній архів —
  теж знахідка.
- `1` — CDX-сервер не відповів після трьох спроб — їхнє навантаження,
  не ваш ввід. Перезапустіть пізніше.
- `2` — неправильні аргументи (порожня ціль, без крапки в домені,
  ліміт поза межами).
