# Перевірка CWV

Що відчувають реальні користувачі Chrome — сторона **поля** в
лінії продуктивності: LCP / INP / CLS **p75 по форм-факторах**
(телефон і десктоп окремо, проти офіційних меж), **fallback
URL-на-origin** сказаний вголос (тонкі сторінки не мають запису;
origin-числа — по всьому сайту), **тренд за 25 тижнів**
(лінійна діаграма) і **заголовок лаба-проти-поля** — розбіжність
між цим звітом і лабораторними інструментами (Server Timing, HAR
Analyze) і є дієвим висновком.

Лабораторні інструменти кажуть, *що* повільно; цей — чи *поле*
це бачить.

---

## Перед запуском

1. Введіть **URL** — сторінка для даних по сторінці; корінь сайту
   читає origin-запис в будь-якому разі.
2. Вкажіть **CrUX API key** — безкоштовний: Google Cloud Console
   → увімкнути *Chrome UX Report API* → Credentials → Create API
   key. Через `CRUX_API_KEY` (Keychain у PyShell); без нього
   скрипт виходить з інструкцією, а не з вигаданими числами.
   Після повторного відкриття скрипта поле виглядає **порожнім**:
   PyShell тримає ключ у Keychain і принципово не повертає секрет
   у форму. Це не втрачене значення — натисніть Run і перевірте.
   І лише якщо сам запуск усе одно завершується `CRUX_API_KEY is
   not set`, значення справді не дійшло до скрипта.
3. **Prepare Env** — встановлює `requests`. Натисніть **Run**
   (⌘↩).

## Поля

### Target

- **URL** — сторінка або origin для пошуку.

### Feed

- **CrUX API key** — безкоштовний ключ Google (секрет у env).
- **Per-request timeout (s)** — 5–60, типовo 30.

## Результат

- **Вкладка Results** — таблиця (форм-фактор · метрика · p75 ·
  оцінка: 🟢 good ≤ LCP 2.5 с / INP 200 мс / CLS 0.10, 🟠 needs
  improvement, 🔴 poor), тренд p75 за 25 тижнів (лінійна
  діаграма) і звіт:
  - **Рівень даних** — page чи origin, у заголовку; origin-fallback
    несе свою примітку («по всьому сайту, не ця сторінка»).
  - **Тренд** — та сама історія p75, що й на діаграмі, але
    текстом (перше → останнє, напрямок, оцінка на кінець), щоб
    `report.md` ніс її й поза вкладкою Results. Це запис
    ORIGIN по всіх форм-факторах — сказано в самій секції — і
    він потребує двох періодів без прогалин: менше — секції
    просто немає, нічого не вгадується.
  - **Заголовок лаба-проти-поля** — поле червоне + лаба зелена =
    лаба прогавила умови відвідувачів; поле зелене + лаба
    червона = довіряйте полю в ранжуванні, лабі — в діагностиці.
  - Відсутність історії — примітка («не вгадано»), ніколи
    плоска лінія.
- **Артефакти** — `report.md`, `findings.json` (p75 по
  форм-факторах та історія, машиночитно).

## Коди виходу

| Код | Значення |
|---|---|
| 0 | відпрацювало; звіт — картина поля |
| 1 | нема ключа, або в CrUX нема даних ні для URL, ні для origin |
| 2 | помилкові аргументи: URL без http(s) |

## Пов'язане

- **Server Timing / HAR Analyze / Cache Check** — лабораторний
  бік: що повільно і чому.
- **Load Test** — деградація під навантаженням.
- **SEO Checks** — прохід по всьому сайту.
